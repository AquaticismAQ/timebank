# TimeBank 部署费用评估

> **规划基线，并非供应商报价。** 编制日期：2026-08-20。所有价格均为公开价目表的规划输入，未含税、促销、教育折扣、议价折扣和汇率变动。采购前必须在对应云厂商计算器中复核，并取得书面报价。

## 1. 结论摘要

本评估面向单所学校：**学生 3,000 人、教职员工账号 300 个、峰值并发在线 300 人**。并发目标与现有技术设计一致；预期持续峰值约为 60 req/s，突发目标约为 200 req/s。证据材料通过对象存储直传，不经过应用服务器。

每个地区均给出两种方案：

| 方案 | 用途 | 建议 |
| --- | --- | --- |
| 单服务器 | 最低成本试点或非关键环境；应用、Nginx 与 MySQL 共用一台主机 | **不应作为学校生产上线方案。** 主机故障将同时中断应用和数据库。 |
| 双服务器热备 | 同一区域/AZ 组内两台主机：均运行应用实例；MySQL 主库异步复制到第二台主机；故障时人工提升副本 | **生产最低方案。** 可支撑 B7 的备份/恢复与故障切换工作，但不是自动高可用，仍需负载均衡和运维演练。 |

当前仓库设计要求面向中国大陆学校的部署将数据和节点保留在中国大陆。因此，海外部署是另一司法辖区/数据驻留选项，不能作为大陆系统的故障转移区域；在任何学生数据出境前，必须取得新的机构和法律审批。

## 2. 通用资源与测算假设

| 项目 | 本评估采用的规格 | 原因 |
| --- | --- | --- |
| 每台生产主机计算资源 | 8 vCPU、32 GiB 内存、Linux | 为 Spring Boot、Nginx、MySQL、操作系统缓存及共机部署时 60–70% 的 MySQL Buffer Pool 留出空间。 |
| 每台本地 SSD | 600 GB SSD：100 GB 操作系统/应用/日志 + 500 GB MySQL/binlog/余量 | 设计中的稳定态数据库仅约 10–20 GB，但主机还需容纳 binlog、升级、导入导出及恢复余量。 |
| 应用数据库连接池 | 每个生产应用实例 20–30 个连接 | 现有配置已明确当前 5 个连接仅适用于资源不足的共享测试机。 |
| 公网与内网 | 大陆采用 10 Mbps 固定出网带宽；两台主机间至少 1 Gbps 私网能力 | 证据文件直传对象存储，10 Mbps 足以承载 API/UI 流量。持续使用达到 70% 前后时应观测并升级。 |
| 对象存储 | 私有 Bucket、预签名上传/下载 URL、生命周期：标准 → 90 天后低频 → 1 年后归档 | 这是计划中的 B3F 对本地证据磁盘的替代方案。 |
| 证据存储容量 | 稳定态 700 GB；每月 100 GB 公网下载流量 | 现有设计预计留存证据为 550–700 GB，本评估按保守上限计。 |
| 邮件量 | 180,000 收件人投递/年，即 15,000/月 | 将既有 5,000 名学生、300,000/年的设计数字按 3,000 名学生同比缩放。每位收件人独立计费。 |
| 备份 | 初期平均计费对象/快照容量 100 GB，后续以实际压缩备份结果校正 | 物理夜备与 binlog 归档必须实现并经过恢复测试；此处是预留，不代表当前已经具备备份。 |

这些数字不能证明已经通过 300 人负载测试。负载测试、恢复演练、复制延迟监控和预发布环境演练仍是必须完成的验收工作。

### 3.4 大陆运维说明

1. 双机估算是**人工提升 MySQL 副本的温备/热备**，不是自动故障转移集群。因为使用异步复制，不能承诺零数据丢失；应在恢复/切换演练中测得真实 RPO/RTO。
2. 应从副本执行备份，将 binlog 持续归档至 OSS，并每周恢复到临时实例校验。验证用临时主机需计入预算，不能省略。
3. 证据和大型导出必须使用 OSS 预签名 URL，不能为了转发文件而提高 ECS 带宽。
4. 普通事务通知使用 DirectMail API。附件仅能经 SMTP 发送；敏感证据应始终提供需登录的 TimeBank 链接，而不是邮件附件。

### 3.5 大陆托管 MySQL 备选方案：阿里云 RDS

- gp3 依据预配容量计费，包含 3,000 IOPS / 125 MiB/s 基线，超出部分另计：[EBS 定价](https://aws.amazon.com/ebs/pricing/)及[gp3 指引](https://docs.aws.amazon.com/prescriptive-guidance/latest/optimize-costs-microsoft-workloads/ebs-migrate-gp2-gp3.html)。

- SES Essentials 当前对 0–1,000 万封/月列示 $0.16/1,000 封。附件数据另行收费，因此普通通知邮件不应携带证据文件：[SES 定价](https://aws.amazon.com/ses/pricing/)。

### 4.4 海外运维说明

1. 系统邮件应选 AWS SES，而不是 Google Workspace 邮箱。SES 专为应用投递、额度、退信和送达率设计；除非机构明确要求 SMTP Relay/Gmail API，否则 Google Workspace 更适合作为教职工邮箱。
2. 面向 300 并发用户，两个 MySQL 主机均不得使用 Spot 实例。仅在负载测试和规格验证完成后，才考虑 Savings Plan 或 Reserved Instance。
3. 数据库必须置于私有子网，仅允许应用安全组访问，绝不向互联网暴露 MySQL。
4. 必须从真实用户所在地测试海外延迟。若用户主要在中国大陆，海外访问还会带来用户体验、路由和合规风险，这些风险超出云账单本身。

### 4.5 海外托管 MySQL 备选方案：Amazon RDS for MySQL

生产比较应使用 **Amazon RDS for MySQL Multi-AZ（一个备用库）**。它在第二个可用区维护同步备用库，并能在计划内或非计划故障时自动切换。它明显强于自建的异步副本方案，但“一个备用库”模式中的备用库不是用于读扩展的端点。

| 组件 | 初始托管数据库规格 | 月度规划区间（美元，未含税） | 说明 |
| --- | --- | ---:| --- |
| RDS MySQL，单可用区 | 4 vCPU / 16 GiB 等级、200 GiB 通用 SSD | $420–$540 | 仅供开发或比较；没有备用库。 |
| RDS MySQL，Multi-AZ（一个备用库） | 4 vCPU / 16 GiB 等级、200 GiB 通用 SSD | $840–$1,080 | 建议的生产起始规格；包括主库/备用库的实例时长和存储，但不包括全部备份超额费用。 |

RDS Multi-AZ 方案约比自建双服务器参考方案高 **43–70%**。这一溢价换来同步备用复制和自动数据库故障转移，同时无需自行维护 MySQL 主机补丁、副本提升和物理备份操作。它不会消除应用主机高可用、Schema 变更纪律、最小权限数据库访问、查询/索引监控或恢复测试的责任。

AWS 在 Multi-AZ 部署中对主库和备用库的实例时长、存储均计费；AWS 明确说明，数据库层成本通常约为单可用区的两倍。必须以选定的当前实例族和存储配置在 AWS Pricing Calculator 中取得新加坡区精确报价：[RDS for MySQL 定价](https://aws.amazon.com/rds/mysql/pricing/)及[Multi-AZ 计费说明](https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/USER_OnDemandDBInstances.html)。

| 恢复临时主机 | 每周自动恢复验证所必需 | 使用时间短，但每周都必须纳入预算。 |
| 监控与告警 | 复制延迟、磁盘容量、备份失败、连接池饱和和错误率告警目前仍未建设 | 使用云监控加日志/指标栈；确定保留期后取得服务报价。 |
| WAF/CDN/DDoS、DNS、域名、证书 | 面向互联网的学校系统防护与路由 | 取决于域名、流量和安全策略。 |
| 邮件功能实施 | 服务商适配器、outbox/重试、模板、退信、抑制名单及密码重置投递 | 属于工程/测试成本，不是云资源消耗费。 |
| 一次性迁移与测试数据 | 云文件存储迁移、已有证据传输、性能测试数据集 | 应在 B3F 迁移计划和真实数据量测得后估算。 |
| 税费、ICP备案与法务审查 | 大陆公网服务要求及未成年人个人信息处理；数据出境可能需要独立审批 | 明确未包含；应由学校、法务和财务共同采购/确认。 |

## 6. 采购门槛与下一步

1. 确认学校所在地、大陆数据驻留是否强制、目标 RPO/RTO，以及事故由谁负责处置。
2. 就选定地域和合约期获取最新报价。将本文每个规划预留替换为带日期的计算器导出和报价单编号。
3. **先建设预发布环境**，再建设双机生产、OSS/S3、DirectMail/SES、私网、监控。不能因为已经有单机试点而将它惯性地当作生产基线。
4. 在接收真实学校证据前，完成 B3F 对象存储迁移以及 B7 备份/PITR/恢复/故障切换演练。
5. 执行要求的 300 并发用户负载测试，并根据实测 p95 延迟、数据库指标和对象存储流量调整 CPU、内存、磁盘 IOPS 与公网带宽。
