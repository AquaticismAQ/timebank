# 时间银行 · 法律合规方案（Legal）

> 本文档是《时间银行方案设计》（`TimeBankDesign.md`）的子方案，系统论述在**中国现行法律法规**下，时间银行使用区块链与「时间币」所面临的合法性约束、限制边界与合法化路径。区块链技术实现见 `Blockchain.md`，数据与隐私处理见 `AutoAudit.md`、`ManualAudit.md`。
>
> **免责声明**：本文为合规设计参考，非正式法律意见。项目正式落地前，应由学校法务或专业律师结合最新法规与地方监管口径进行专项审查。

## 1. 总体合规定位

时间银行的合规底层逻辑只有一句话：**它是校内教育性的「公益荣誉/积分」体系，不是金融工具，也不是任何形式的代币或货币。**

- **区块链仅用于「存证」**，记录志愿服务与荣誉的事实指纹，**不用于交易、不发行代币**。
- **「时间币」仅为校内积分记账单位**，**不可提现、不可转让、不与法币挂钩、不进入二级流通**。
- **兑换是校内积分核销**，不构成支付、结算或金融交易。

只要守住"非货币、非交易、非金融"三条红线，整体法律风险即可控。

## 2. 区块链应用的合法性约束

### 2.1 区块链信息服务备案（强制）

- **依据**：《区块链信息服务管理规定》（国家网信办，2019）。
- **要求**：向社会公众提供区块链信息服务的主体须**履行备案手续**，取得备案编号。
- **落地**：学校作为应用方，应核实所选区块链服务商（如 BSN/文昌链、蚂蚁链等）已完成备案，并保留其备案号；如自建链对外提供服务，须自行备案。

### 2.2 严禁代币发行与虚拟货币交易（最高红线）

- **依据**：
  - 《关于防范代币发行融资风险的公告》（七部委，2017，即"94 公告"）。
  - 《关于进一步防范和处置虚拟货币交易炒作风险的通知》（十部委，2021，即"924 通知"）。
- **禁止**：发行任何代币（Token）、首次代币发行（ICO）、挖矿、虚拟货币兑换/交易/定价、与法币或外汇兑换。
- **落地**：系统**绝不发币、不挖矿、不上交易所**；时间币不得具备虚拟货币的任何特征（详见第 3 节）。

### 2.3 必须使用合规联盟链，弃用公链

- **理由**：以太坊、Solana 等带原生加密代币的公有链天然涉及虚拟货币，触碰 94/924 红线。
- **落地**：采用**国内已备案的开放联盟链**（推荐文昌链/BSN，备选蚂蚁链等），燃料费以**人民币**结算，用户端无私钥、无钱包、无加密资产（详见 `Blockchain.md`）。

### 2.4 数据安全与境内存储

- **依据**：《网络安全法》《数据安全法》《个人信息保护法》。
- **要求**：链节点与数据存储应在**境内**；避免数据跨境；落实数据分级与安全保护义务。
- **落地**：链上**只存哈希指纹**，不存明文个人信息；原始数据与脱敏图存于境内业务库/对象存储。

### 2.5 区块链存证的司法效力（正向利用）

- **依据**：《人民法院在线诉讼规则》（2021）及司法实践（杭州互联网法院等）确认，通过区块链等可信技术存储、固定的电子数据，符合条件的可作为证据采信。
- **价值**：上链存证可提升志愿服务与荣誉记录的防篡改性与第三方公信力（详见 `Blockchain.md` 的 TRUST 模型）。

## 3. 「时间币」面临的法律限制

「时间币」是合规风险最敏感的环节，核心是**防止其被认定为"代币/虚拟货币/可流通价值凭证/预付卡"**。

### 3.1 不得构成"虚拟货币/代币"

- 不得发行、不得挖矿、不得定价、不得与法币或虚拟货币兑换。
- 不得宣称"增值""理财""投资"等金融属性。

### 3.2 不得具备金融/支付属性

- **依据**：《非金融机构支付服务管理办法》《电子商务法》。
- **限制**：时间币不得用于**对外支付、结算、找零、提现**，不得在学生之间或与校外主体之间**自由转让流通**。
- **借贷功能注意**：`TimeBankDesign.md` 中的"时间币借贷"应严格定性为**校内服务时长的记账性预支**，不计息、不涉资金、不可兑现，避免被解读为信贷/类金融业务。

### 3.3 预付卡/单用途消费卡监管的规避

- **依据**：《单用途商业预付卡管理办法（试行）》（商务部）。
- **风险**：若时间币可广泛兑换实物商品且具备储值/预付特征，可能被类比预付卡监管。
- **落地**：兑换以**荣誉、成长激励、校内非营利性权益**为主，弱化"购物储值"属性；不与现金充值挂钩。

### 3.4 个人信息与未成年人保护

- **依据**：《个人信息保护法》《未成年人保护法》《儿童个人信息网络保护规定》。
- **要求**：处理未成年人（尤其不满 14 周岁儿童）个人信息须取得**监护人同意**；遵循最小必要原则；链上不得写入明文个人信息或可识别肖像。
- **落地**：见证者手机号、UnionID、监护人签名等敏感项**仅存加密哈希**；端侧脱敏、原图不落盘（详见 `AutoAudit.md`）。

### 3.5 与升学/评优挂钩的审慎性

- 时间币与综合素质评价、升学材料挂钩时，须保证评价的**真实、公平、可追溯**，防止寻租；高价值证书应配合跨校盲评（见 `AutoAudit.md`），并遵循教育主管部门相关规定。

### 3.6 术语合规（对外表述）

全系统**禁用**以下表述：`Token、代币、数字货币、加密货币、挖矿、提现、钱包、炒币、增值理财`。
对外统一称：**「公益积分 / 爱心积分 / 服务时长 / 荣誉存证 / 成长档案」**。

## 4. 如何合法化（合规设计路径）

| 合规要点 | 具体做法 |
| --- | --- |
| **定性为积分而非货币** | 章程明确"时间币=校内公益积分/荣誉记账单位"，无金融属性 |
| **守住三条红线** | 不发币、不交易、不提现；不可转让、不可兑现金、不与法币挂钩 |
| **区块链只存证不交易** | 联盟链仅写哈希存证；兑换在中心化业务库记账，不上链转账（见 `Blockchain.md`） |
| **使用备案联盟链** | 选用已备案的国内开放联盟链，人民币计费，用户无私钥 |
| **主体实名** | 以学校/教育主管部门/合法登记 NGO 为运营主体，完成企业级 KYC |
| **监护人同意** | 注册与信息处理环节取得监护人授权，提供隐私政策与告知 |
| **数据最小化与境内化** | 链上只存哈希；敏感字段仅加密哈希；数据与节点在境内 |
| **兑换去金融化** | 兑换限于荣誉、成长激励、校内非营利权益，不储值、不充值现金 |
| **借贷去信贷化** | 借贷定性为时长记账预支，不计息、不涉资金 |
| **术语规范** | 对内对外禁用代币类表述，统一用"积分/荣誉/存证" |
| **法务审查** | 落地前由学校法务/律师做专项合规审查，留存合规文件 |

## 5. 合规检查清单（上线前自检）

- [ ] 是否**未发行任何代币**、无挖矿、无虚拟货币兑换？
- [ ] 所选区块链服务商是否**已完成网信办备案**并留存备案号？
- [ ] 链上是否**只存哈希指纹**、无明文个人信息与肖像？
- [ ] 时间币是否**不可提现、不可转让、不与法币挂钩**？
- [ ] 兑换是否限于荣誉/非营利权益，**不具备储值预付特征**？
- [ ] 是否取得**监护人同意**并提供隐私政策？
- [ ] 数据与链节点是否**全部位于境内**？
- [ ] 对外文案是否**已剔除代币类敏感表述**？
- [ ] 是否已完成**法务/律师专项审查**并留档？
